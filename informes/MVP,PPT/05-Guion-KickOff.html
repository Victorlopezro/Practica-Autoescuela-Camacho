🎤 Cómo Comenzar (0-3 min)

Tu Introducción

"Buenos días/tardes, me llamo [nombre] y voy a realizar mis prácticas curriculares de [Duración] horas durante las próximas 3 semanas. El objetivo de hoy es conocer mejor sus necesidades y definir juntos un alcance realista para el proyecto."

💡 Clave: No te presentes como "el que va a hacer todo". Preséntate como "el que va a entregar un sistema funcional".

❓ Preguntas Clave (10-18 min)

Preguntas Vitales (hacer primero)

1. ¿Qué software utilizan actualmente?
Para saber integración posible
2. ¿Tienen datos históricos de alumn@s?
Para saber si IA es viable
3. ¿Cuál es el problema más urgente que tienen?
Para priorizar funcionalidades
4. ¿Cuántos alumn@s gestionan al mes?
Para dimensionar el sistema

Preguntas de Recursos

5. ¿Qué acceso técnico pueden darme?
Servidor, BD, etc.
6. ¿Cuántos instructores y vehículos tienen?

Preguntas de Expectativas

7. ¿Prefieren un POC funcional o un sistema más completo?
8. ¿Tienen presupuesto para WhatsApp Business API?
9. ¿Tienen política de protección de datos (RGPD)?

💬 Cómo Explicar las Limitaciones

✅ SÍ Decir

  • "He diseñado un MVP realista que asegura un sistema funcional entregable"
  • "Las funcionalidades avanzadas pueden desarrollarse en fases futuras"
  • "Email es gratuito, WhatsApp tiene costes"
  • "Sin datos históricos, la IA predictiva no funciona"

❌ NO Decir

  • "Solo tengo 90 horas, no puedo hacer mucho"
  • "No sé si llegaré a terminar algo"
  • "Todo es muy complicado"
  • "Necesito muchas cosas que probablemente no tienen"

🎯 Cómo Tratar Temas Específicos

IA Predictiva

Cuando pregunten por predecir si un alumn@ aprobará:

"Para que la IA prediga con exactitud, necesitamos datos históricos de alumn@s que ya han fatto el examen: notas de test, número de prácticas, errores frecuentes, tiempo entre clases, asistencia, etc.

Si no tienen esos datos: puedo implementar un sistema de reglas básico que funcione desde el primer día (ej: "si +20 prácticas y -5 errores = probabilidad alta"). Esto NO es IA avanzada, pero deja la estructura lista para IA futura."

WhatsApp

Cuando pregunten por WhatsApp automático:

"Recomiendo empezar con email automático porque es gratuito, no tiene restricciones y funciona inmediatamente. WhatsApp Business API tiene costes (aproximadamente X euros al mes dependiendo del volumen) y requiere aprobación de Meta. Si el presupuesto lo permite, podemos incluirlo después."

Comercial Virtual / Chatbot

Cuando pregunten por chatbot 24/7:

"Un asistente virtual que converse naturalmente requiere tecnologías de Procesamiento de Lenguaje Natural (NLP) muy avanzadas y muchas horas de desarrollo. Para 90 horas no es viable. Lo que sí podemos hacer es un sistema de respuestas automáticas básico por email o WhatsApp."

🏁 Cómo Cerrar la Reunión (25-30 min)

Pasos para cerrar

  1. Resumir acuerdos: "Entonces, los puntos clave son..."
  2. Confirmar prioridades: "Quedamos en que priorizamos X"
  3. Establecer comunicación: "Nos comunicaremos por email/correo"
  4. Definir siguiente paso: "La próxima semana we'll tener otra reunión para revisar avances"
  5. Agradecer: "Gracias por su tiempo y disposición"
💡 Después de la reunión: Envía un email resumiendo lo hablado y los acuerdos alcanzados. Queda profesional.

📝 Notas Rápidas durante la Reunión

Información Qué anotar
Software actual Nombre, versión, si tiene API
Datos históricos Cuántos registros, formato (Excel, papel, sistema)
Volumen Número alumn@s/mes, instructores, vehículos
Problema principal Proceso que más tiempo roba
Persona de contacto Nombre, email, teléfono, disponibilidad
Presupuesto Para APIs externas, hosting, etc.

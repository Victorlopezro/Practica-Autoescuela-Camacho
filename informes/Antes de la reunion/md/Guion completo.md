**Guion y Guía para Reunión de Kick Off --- Proyecto Autoescuela IA**

**Objetivo de la reunión**

-   Entender qué necesita realmente la empresa.

-   Priorizar funcionalidades para un proyecto limitado a 90 horas.

-   Detectar riesgos técnicos y económicos desde el inicio.

-   Definir un alcance realista para un MVP o POC funcional.

-   Aclarar recursos disponibles y posibles costes externos.

**1. Introducción (2-3 min)**

**Qué decir al empezar**

"Antes de empezar a definir funcionalidades concretas, creo que lo más
importante es entender qué necesidades considera prioritarias la
empresa, ya que el proyecto inicial incluye muchas áreas diferentes y el
tiempo de prácticas es limitado. La idea de esta reunión es definir qué
tendría más valor desarrollar primero y qué partes podrían dejarse para
una fase futura."

**2. Pregunta principal de priorización (5 min)**

**Pregunta clave**

"De todas las funcionalidades planteadas, ¿cuáles consideráis más
importantes o más urgentes para el negocio actualmente?"

**Posibles respuestas esperadas**

-   Organización de clases.

-   Atención al cliente.

-   Captación de alumnos.

-   Automatización administrativa.

-   IA predictiva.

-   WhatsApp.

-   Tests teóricos.

**3. Tu valoración técnica y de viabilidad (5-7 min)**

**Qué explicar después**

"Desde el punto de vista técnico y teniendo en cuenta las 90 horas
disponibles, recomendaría priorizar funcionalidades que puedan aportar
valor rápido y que además sirvan como base para futuras ampliaciones."

**4. Prioridades recomendadas**

**PRIORIDAD ALTA (recomendado para MVP)**

**1. Agenda inteligente y reservas de clases**

Motivos:

-   Impacto directo en el día a día.

-   Fácilmente ampliable.

-   Base para automatizaciones futuras.

-   Permite demostrar un sistema funcional completo.

**2. Seguimiento de progreso de alumnos**

Motivos:

-   Necesario para cualquier IA futura.

-   Permite registrar evolución y estadísticas.

-   Puede conectarse después con predicción de aprobados.

**3. Automatización de mensajes (WhatsApp o email)**

Motivos:

-   Mucho valor operativo.

-   Reduce trabajo manual.

-   Puede automatizar:

    -   recordatorios

    -   citas

    -   exámenes

    -   avisos

**5. Funcionalidades con riesgo o complejidad alta**

**IA predictiva de aprobado/suspenso**

**Qué explicar**

"Esta parte es interesante, pero depende completamente de los datos
históricos disponibles."

**Riesgos**

-   Puede no haber suficientes datos.

-   Datos mal estructurados.

-   Falta de histórico de alumnos.

-   El modelo puede no ser preciso inicialmente.

**Preguntas importantes**

-   ¿Guardan resultados históricos?

-   ¿Tienen estadísticas de alumnos anteriores?

-   ¿Cómo deciden actualmente si alguien está preparado?

**Teórica adaptativa con IA**

**Riesgos**

-   Necesita banco de preguntas estructurado.

-   Requiere clasificar preguntas por temática.

-   Mayor tiempo de desarrollo.

**Posible solución**

"Podría hacerse una versión básica donde el sistema detecte temas con
más fallos y recomiende tests relacionados."

**6. Tema importante: Recursos Open Source (3 min)**

**Qué explicar claramente**

"La intención del proyecto es utilizar principalmente herramientas open
source para evitar costes elevados y facilitar que el sistema pueda
mantenerse o ampliarse más adelante."

**Ejemplos que puedes mencionar**

-   Backend open source.

-   Bases de datos gratuitas.

-   Modelos IA open source.

-   Automatizaciones gratuitas o autoalojadas.

**7. Tema importante: WhatsApp API y costes (3-4 min)**

**Qué debes explicar**

"Hay que tener en cuenta que automatizar WhatsApp de forma profesional
normalmente requiere usar WhatsApp Business API o plataformas
intermedias, y eso puede implicar costes externos."

**Riesgos y limitaciones**

**Costes**

-   Meta cobra por conversaciones/API.

-   Algunos proveedores cobran mensualidades.

**Limitaciones**

-   Necesidad de verificar empresa.

-   Restricciones anti-spam.

-   Plantillas obligatorias para ciertos mensajes.

-   Tiempo de aprobación de Meta.

**Importante aclarar**

"No todo WhatsApp puede automatizarse gratuitamente de forma estable o
legal."

**Preguntas que debes hacer**

-   ¿Ya usan WhatsApp Business?

-   ¿Estarían dispuestos a asumir costes API?

-   ¿Quieren automatización completa o solo avisos básicos?

-   ¿Prefieren alternativas como email/SMS en algunos casos?

**8. Funcionalidades recomendadas para dejar en segunda fase**

**Baja prioridad para 90 horas**

**Comercial virtual 24/7 completo**

Motivos:

-   Mucha complejidad.

-   Requiere IA conversacional robusta.

-   Integraciones externas.

**Base de conocimiento avanzada**

Motivos:

-   Requiere documentación estructurada.

-   Mucho contenido que preparar.

**Gestión avanzada de mantenimiento de vehículos**

Motivos:

-   Menor impacto inicial.

-   Puede hacerse más adelante fácilmente.

**9. Preguntas importantes para cerrar la reunión**

**Sobre negocio**

-   ¿Cuál es el principal problema que quieren resolver?

-   ¿Qué proceso les consume más tiempo?

-   ¿Qué parte consideran imprescindible?

**Sobre tecnología**

-   ¿Qué software usan actualmente?

-   ¿Existe alguna base de datos?

-   ¿Tienen hosting o servidores?

-   ¿Quién gestionará el sistema después?

**Sobre alcance**

-   ¿Prefieren un sistema pequeño pero funcional o muchas
    funcionalidades básicas?

-   ¿Esperan un MVP, una demo o un sistema operativo?

**10. Cierre de la reunión**

**Qué decir**

"Con lo hablado hoy puedo definir un alcance más realista y preparar una
propuesta inicial priorizando las funcionalidades con más impacto y más
viables dentro del tiempo disponible."

**Recomendación técnica final**

**Lo más razonable para 90 horas**

**MVP recomendado**

-   Agenda inteligente.

-   Reservas de clases.

-   Seguimiento de alumnos.

-   Automatización básica de mensajes.

-   Base preparada para IA futura.

**IA predictiva**

Solo si:

-   Existen datos suficientes.

-   La empresa puede proporcionarlos rápidamente.

**WhatsApp**

Viable, pero:

-   probablemente con costes externos,

-   limitaciones de Meta,

-   y necesidad de cuenta Business/API.

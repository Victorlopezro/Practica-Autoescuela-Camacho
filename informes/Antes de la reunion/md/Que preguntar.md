**Requisitos pendientes para definir en el Kick Off**

**1. Objetivo general del proyecto**

Definir claramente:

- Qué problema principal quiere resolver la autoescuela. 
- Qué funcionalidades son prioritarias. 
- Qué partes deben ser un MVP/POC y cuáles quedarían para fases futuras. 
- Qué esperan obtener al finalizar las prácticas. 
-----
**2. Requisitos funcionales pendientes**

**Sistema de predicción de aprobado/suspenso con IA**

Pendiente definir:

- Qué datos históricos tienen disponibles: 
  - notas de test 
  - número de prácticas 
  - errores frecuentes 
  - tiempo entre clases 
  - asistencia 
  - convocatorias previas 
- Cómo determinan actualmente si un alumno está preparado. 
- Qué precisión esperan del sistema. 
- Si desean recomendaciones automáticas para el alumno o para el profesor. 
- Quién podrá ver las predicciones. 
-----
**Reservas y seguimiento de clases prácticas**

Necesario aclarar:

- Cómo gestionan actualmente las reservas. 
- Si ya usan algún software de gestión. 
- Reglas de negocio: 
  - cancelaciones 
  - cambios de profesor 
  - límites de reservas 
  - horarios disponibles 
- Qué información quieren visualizar: 
  - progreso 
  - horas realizadas 
  - evolución 
  - incidencias 
-----
**Agenda inteligente**

Pendiente definir:

- Qué tareas debe automatizar: 
  - asignación de clases 
  - optimización de horarios 
  - evitar solapamientos 
  - recordatorios 
- Si debe integrarse con Google Calendar, Outlook u otros sistemas. 
-----
**Comercial virtual vía WhatsApp**

Importante concretar:

- Qué acciones podrá realizar: 
  - responder dudas 
  - informar precios 
  - recoger datos 
  - generar preinscripciones 
  - enviar documentación 
- Si utilizarán: 
  - WhatsApp Business API 
  - herramientas externas 
  - proveedor oficial 
- Horarios y límites de automatización. 
- Necesidad de derivar a una persona real. 
-----
**Automatización de mensajes de examen**

Necesario preguntar:

- Cómo reciben actualmente las fechas de examen. 
- Formato de los datos. 
- Cuándo deben enviarse los mensajes. 
- Si quieren confirmación automática del alumno. 
-----
**Automatización de facturas**

Pendiente definir:

- Software actual de facturación. 
- Formato de facturas. 
- Integraciones necesarias. 
- Si necesitan: 
  - generación automática PDF 
  - envío por correo 
  - control de pagos 
  - avisos de impago 
-----
**Teórica adaptativa con IA**

Necesario concretar:

- Si ya tienen base de preguntas/test. 
- Cómo clasifican los temas. 
- Qué métricas quieren: 
  - tasa de fallo 
  - tiempo de respuesta 
  - evolución del alumno 
- Si desean: 
  - generación automática de preguntas 
  - recomendación de temas 
  - simulacros personalizados 
-----
**Mantenimiento de vehículos**

Preguntar:

- Cuántos vehículos gestionan. 
- Qué mantenimientos desean controlar: 
  - ITV 
  - revisiones 
  - aceite 
  - neumáticos 
  - seguros 
- Con cuánta antelación quieren alertas. 
-----
**Base de conocimiento y atención al cliente**

Pendiente definir:

- Qué documentación existe actualmente: 
  - preguntas frecuentes 
  - normativa 
  - precios 
  - procedimientos 
- Quién actualizará la información. 
- Qué canales usarán: 
  - web 
  - WhatsApp 
  - recepción 
-----
**3. Requisitos técnicos pendientes**

**Infraestructura**

Necesario preguntar:

- Si tienen servidores o todo será cloud. 
- Presupuesto aproximado. 
- Restricciones tecnológicas. 
- Preferencia por software open source o comercial. 
-----
**Accesos y datos**

Importante definir:

- Qué acceso tendrás: 
  - bases de datos 
  - software actual 
  - documentos 
  - APIs 
- Protección de datos y RGPD. 
- Permisos de usuarios. 
-----
**Integraciones**

Confirmar:

- Programas actuales de gestión. 
- Sistemas externos necesarios: 
  - WhatsApp 
  - correo 
  - calendarios 
  - facturación 
  - DGT si aplica 
-----
**4. Requisitos organizativos**

**Personas implicadas**

Definir:

- Responsable del proyecto. 
- Persona de contacto diaria. 
- Quién valida entregas. 
- Disponibilidad para reuniones. 
-----
**Metodología y seguimiento**

Preguntar:

- Cómo quieren revisar avances. 
- Frecuencia de reuniones. 
- Entregables esperados. 
- Fechas importantes. 
-----
**5. Riesgos iniciales detectados**

Conviene mencionarlos de forma profesional:

- Posible falta de datos históricos suficientes para IA predictiva. 
- Limitaciones de WhatsApp Business API. 
- Tiempo limitado de prácticas para implementar todas las funcionalidades. 
- Dependencia de software externo. 
- Protección de datos personales de alumnos.
